# Reseam documentation

Reseam applies community-built patches to Android apps on the device. These docs are for people who build on it.

New to writing patches? Start with [Start a bundle](/docs/authoring/start/): it copies the [patch bundle template](https://git.reseam.app/reseam/patches-template), builds it, and runs it on an app in a few minutes.
